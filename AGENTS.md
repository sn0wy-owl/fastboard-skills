# AGENTS.md — правила этого репозитория

Репозиторий командных скиллов для агентских систем. Этот файл читают Codex CLI, Cursor,
Gemini CLI, Goose, OpenCode и другие агенты, работающие по стандарту `AGENTS.md`;
Claude Code читает `CLAUDE.md`, который ссылается сюда.

## Что здесь лежит

- `skills/<имя>/SKILL.md` — **единственный источник правды** по каждому скиллу.
  Формат — открытый стандарт Agent Skills (agentskills.io): YAML-frontmatter + markdown.
- `skills/<имя>/references/` — длинные методички, загружаются по требованию.
- `skills/<имя>/templates/` — скелеты файлов, которые скилл копирует и правит.
- `skills/<имя>/scripts/` — исполняемые проверки.
- `scripts/install.mjs` — раскладка скиллов по каталогам агентских систем.
- `scripts/validate-skills.mjs` — валидатор frontmatter и ссылок.

Каталоги `.claude/skills/`, `.cursor/skills/`, `.agents/skills/`, `.hermes/skills/` —
**сгенерированные** (ссылки на `skills/`). Не редактировать и не коммитить: изменения,
сделанные внутри них, будут потеряны, а расхождение копий — главный источник багов
в этом репозитории. Правь `skills/<имя>/…` и перезапусти `node scripts/install.mjs`.

## Правила работы со скиллами

1. **Имя каталога = `name:` во frontmatter.** Только `a-z`, `0-9` и одиночные дефисы, до 64
   символов, без ведущего/замыкающего дефиса.
2. **`description` — это триггер.** Агент читает только его, решая, грузить ли скилл. Формат:
   что делает + когда применять, с ключевыми словами пользователя (в том числе русскими,
   если по-русски формулируют задачу).
3. **Процедура, а не лог.** В теле — шаги, инварианты, грабли, приёмы. Не переносить номера
   задач, даты, PR и истории инцидентов: через месяц это шум.
4. **Один факт — одно место.** Если правило уже описано в `references/`, в `SKILL.md` — ссылка
   на файл, а не копия.
5. **Все пути к вспомогательным файлам — от каталога скилла** (`references/x.md`,
   `templates/y.html`) и только те, что реально лежат в репозитории.
6. **Язык:** тело — по-русски, frontmatter и ключевые слова — с английскими терминами, чтобы
   скилл срабатывал и у англоязычного агента.
7. Проверка перед коммитом: `node scripts/validate-skills.mjs` — то же самое гоняет CI.
8. Процесс изменений (ветка, PR, версионирование, definition of done) — в
   [`CONTRIBUTING.md`](CONTRIBUTING.md). Если тебя просят изменить скиллы в этом репозитории,
   работай по нему: отдельная ветка, один скилл на изменение, проверки перед PR.

## Чего не делать

- Не хардкодить абсолютные пути вида `C:\Users\<кто-то>\…` — скилл должен работать
  на машине любого участника. Пути к личным артефактам допустимы только как примеры
  и должны быть помечены как пример.
- Не добавлять секреты, токены, строки подключения, выгрузки боевых данных.
- Не добавлять зависимости, которых нет у всех: скилл должен работать на Python 3 stdlib,
  `node` и инструментах агента.
