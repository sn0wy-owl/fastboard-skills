# Карта платформы FastBoard

## Рабочие области
1. **Менеджер проектов** — потоки (папки) и проекты. Новые проекты создаются только в личном потоке «Черновики»; публикация = ПКМ по проекту → «Переместить» в общий поток. ПКМ также: копировать, удалить, «Защитить» (запрет изменений), откат к версии (хранится до 100 версий).
2. **Конструктор дашбордов** — холст; виджеты слева, настройки справа, страницы сверху. «Режим просмотра» имитирует зрителя. Экспорт графика в Excel — через ПКМ. Экспорт/импорт страниц между проектами.
3. **Диспетчер данных** — Скрипт загрузки (подключения, SQL-секции, Запустить, Настройки импорта, Расписание) и Модель данных (связи, метаданные: плотность ключей 100% = полное соответствие, дубликаты; несколько независимых моделей в проекте).
4. **Панель администратора** (роль Администратор; вход из меню в правом верхнем углу менеджера, URL содержит adminUser): Пользователи (данные, черновики, подключения, потоки, группы), Группы, Активные директории (импорт из домена), Подключения (доступы; создавать здесь нельзя), Задания (мониторинг CRON), Лицензии (Аналитик / Разработчик, LIFO при сокращении), Потоки, Настройки (версии проектов: количество/возраст; шрифты системы).

## Роли (каждая включает предыдущую)
Зритель → Аналитик (конструктор, свои потоки/черновики, SQL к готовой модели; диспетчер данных закрыт) → Разработчик (+ все коннекторы, скрипт загрузки, модель, RLS) → Администратор (+ админка, лицензии, все черновики).

## Безопасность
- SLS — доступ к потокам (управление/использование).
- PLS — доступ к страницам проекта.
- RLS — фильтрация строк, настраивается в модели через переменные (регион ↔ менеджер), тестируется «Предпросмотр RLS» в настройках проекта.

## Источники данных
- Файлы: XLSX/XLS, CSV, TXT, JSON, XML (+мультифайловая загрузка из папки сервера; заголовки с N-й строки; исключение пустых столбцов).
- СУБД: ClickHouse, PostgreSQL (+GreenPlum), MSSQL, MySQL, Oracle, Hive.
- REST-API — через Swagger `<backend>/docs/swagger`, метод «Создание источника данных»:
```json
{ "name": "API.CBR", "driver": "rest-api",
  "credentials": { "url": "https://www.cbr-xml-daily.ru/daily_json.js",
                   "method": {"value": "GET"}, "format": {"value": "json"} } }
```
JSON разворачивается в плоскую таблицу: `Valute.AUD.Value` → `Valute_AUD_Value`. Ответ 201 + isValid=true = готово; при 401 — авторизоваться в FastBoard и повторить.

## Обновление по расписанию
Скрипт загрузки → «Расписание»: ежечасно/ежедневно/еженедельно (месячное на 31-е сработает только в месяцах с 31 днём). Мониторинг — админка → «Задания». Учитывай зависимости слоёв (сначала ETL-проект, потом витрины).
