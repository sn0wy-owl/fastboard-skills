# FastBoard UI — проверено на практике (UI ~v2.0.2)

Инстанс: **целевой стенд пользователя** (URL не хардкодить; логинится пользователь сам).
Swagger: `https://<stand-front>/back/docs/swagger` (basic auth — пароль у пользователя, агент не вводит).
Документация: https://help.fastboard.online/user/
Гипотеза пользователя: макеты можно делать импортом JSON (кнопка «Импортировать» в Черновиках; экспорт проекта — проверить через ПКМ по проекту). Проверить и задокументировать формат.
Учебный проект: «Claude_Учебный» (Черновики) — рабочий пример: подключение 03/Example.xlsx → скрипт → модель → комбо-виджет с реальными данными.
Боевой проект: «Анализ ДДС (Claude)» (Черновики) — данные из подключения ДДС23 (файл «ддс 1 полугодие к2 (1).xlsx», таблица List_1, ~26.7 тыс строк).

## Данные ДДС23 (List_1) — структура
Поля (все из Excel → Nullable(String), кроме INN/Kontragent_INN Int64, Schet Float32): Mesiats и Period («Апрель.2026»), Blok_funktsii («1.1 Приобретение актива…», «2.3 ИРД и ПИР», «5.1 Услуги ЕИО…»), Ukrupnennaia_stat_ia, Stat_ia_dvizheniia_denezhnykh_sredstv, Kontur («ПИФ 3.2», «ПИФ 4.2 СЕРПУХОВ»), Organizatsiia, Kontur_kontragenta («Внешний», «К1», …), Kontragent_naimenovanie, Kontragent_INN, Schet, Subkonto1-3, Kor_schet, Kor_subkonto1-3, Dokument («Поступление на расчетный счет…»/«Списание с расчетного счета…»), VGO (Да/Нет), VGO_kontur («ВГО»/«Без ВГО»), ICO (Да/Нет), Summa (String! отрицательные в СКОБКАХ: «(545)» = -545), file_name, updated_date, fb_created_date.
Разбор суммы: toFloat64OrZero(replaceRegexpAll(Summa, '[^0-9.]', '')) со знаком по Summa LIKE '(%'. Поступления/выплаты = sumIf по признаку скобки (или по префиксу Dokument).

## Механика конструктора (важно для автоматизации браузером)
- Виджет добавляется так: клик по иконке в левой панели → клик по месту на холсте. Drag&drop через синтетический left_click_drag НЕ работает.
- Таблица в модель данных добавляется так же: клик по имени таблицы слева → клик по холсту модели.
- Клик по точке данных виджета сразу применяет фильтр (сверху появляется чип, снять — крестик на чипе). Чтобы выделить виджет без фильтрации — кликать по заголовку/пустой области контейнера.
- Полный каталог виджетов v2.0.2: Комбинированная, Водопад (Мост), Таблица, Тепловая карта, Круговая, Пузырьковая, Медиа-блок, Дерево, iFrame, Диаграмма потоков, SVG-объект, Диаграмма Ганта, What-If переменная. Фильтры: Фильтр-кнопки, Фильтр-список, Фильтр по периоду.
- Правая панель виджета — вкладки: Данные (Реальные данные, Повернуть на 90°, Тип представления: абсолютные/нормированная, объединить/разъединить столбцы; Модель данных; Разрезы; Показатели; SQL; Лимит), Вид (контейнер, стиль, заголовки, навигация по разрезам, легенда, инструменты, инфо, точки данных, подсказка, оси, зум, отступы), События (триггеры, видимость, переход к объекту/гиперссылка, активация, реагировать на фильтры, работать как фильтр, активировать фильтры).
- Агрегации показателя: Сумма, Количество, Кол-во уникальных, Среднее, Мин, Макс, Первое/Последнее значение, По выражению.
- Панель настроек страницы/проекта (клик по пустому холсту): проект (модель по умолчанию, принудительно реальные данные, локальный шрифт, сетка, масштабирование от 1024px, предпросмотр RLS), страница (размеры, границы, цвет, фон-изображение, автообновление, триггеры), палитры (создание/импорт/экспорт, группы цветов), темы (светлая/тёмная/своя).
- Заголовок/подзаголовок виджета: Вид → Заголовки (поля «Основной»/«Дополнительный», размер, цвет, расположение).
- Сохранение: иконка дискеты справа — отдельно «Сохранить проект» в конструкторе и «Сохранить модель» в модели данных. При уходе со страницы предлагает сохранить.

## Диспетчер данных — проверенный поток
1. Вкладка «Скрипт загрузки»: клик по подключению слева (есть Поиск) → модал «Выбрать данные»: чекбоксы таблиц, превью, «Исключить пустые столбцы», алгоритм генерации DROP/ALTER → «Далее» — скрипт генерируется сам (Table/Delete/Create/Read секции с @@@).
2. «Сохранить» → «Запустить» (лог внизу: «Загрузка прошла успешно»). Кнопки: Настройки импорта, Расписание.
3. Вкладка «Модель данных»: добавить таблицы, звезда = основная таблица, снизу «Связи»/«Метаданные»/предпросмотр. ОБЯЗАТЕЛЬНО «Сохранить модель».

## Ловушки SQL-редактора виджета (Редактор Кода)
- Excel-импорт создаёт ВСЕ колонки как Nullable(String) → sum() по ним молча даёт пусто. Лечение: sum(toFloat64OrZero(Sheet.Fact)), сортировка ORDER BY toInt32OrZero(Sheet.MD).
- Enter в редакторе принимает автодополнение (вставляет случайную функцию, напр. gb18030_to_utf8). Писать GROUP BY ... ORDER BY ... ОДНОЙ строкой, после ввода жать Escape.
- Несколько показателей — через запятую в ОДНОЙ строке секции показателей.
- При ошибке синтаксиса «Сохранить» не проходит и НЕсохранённые правки других секций теряются — вносить правки по одной и сохранять.
- Месяцы-строки сортируются по алфавиту — классика: GROUP BY номер_месяца ORDER BY номер_месяца (гранулярность совпадает — значения не множатся).
- Панель ошибок синтаксиса — справа в редакторе кода («Ошибки синтаксиса SQL», секция «Группировки и фильтры»).
